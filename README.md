# 🌐 本地站点导航 + 反向代理网关

一个基于 Flask 的轻量级网关应用，可将 `webs/` 目录下的本地静态网站与外部代理服务统一整合到树形导航页面中，并智能处理代理页面的绝对路径资源加载。

---

## ✨ 功能特性

| 模块 | 说明 |
|------|------|
| **📂 目录扫描与配置解析** | 自动扫描 `webs/` 下的本地站点（含 `index.html`）和全局代理配置 `webs/index.json`。 |
| **🌲 树形导航首页** | 生成可点击的站点列表，区分本地站点（蓝色标签）与代理站点（绿色标签）。 |
| **🏠 本地静态托管** | 直接提供 `webs/` 内静态文件服务，自动重定向目录并返回 `index.html`。 |
| **🔄 反向代理** | 将配置的代理路径请求转发至目标 URL，透传请求方法、头部、Cookie 与数据体。 |
| **🔗 绝对路径资源智能补全** | 当代理页面引用绝对路径资源（如 `/static/style.css`）时，基于 Referer 自动补全代理前缀，确保资源正确加载。 |
| **🚨 自定义错误页面** | 友好的 404 与 502 错误提示页。 |
| **🌙 暗色/亮色主题切换** | 右上角按钮一键切换主题，状态本地保存，默认使用暗色模式。 |
| **📋 精简日志** | 默认仅记录非 200 状态码的请求，减少控制台噪音。 |

## 📁 项目结构
```
project/
├── app.py                 # 主程序入口
├── requirements.txt       # Python 依赖
├── README.md              # 项目说明（本文件）
├── static/                # 可选全局静态文件（不会被代理影响）
├── templates/             # HTML 模板目录
│   ├── index.html         # 树形导航首页（含主题切换）
│   ├── 404.html           # 404 错误页
│   └── 502.html           # 502 错误页
└── webs/                  # 站点根目录（需自行创建）
    ├── index.json         # 全局代理配置文件
    ├── site-a/            # 本地站点示例
    │   └── index.html
    └── another-site/      # 另一个本地站点
        └── index.html
```

## 🚀 快速开始

### 0. 安装Python
在 [Python](https://python.org/downloads/) 官网安装 `Python3.6` 或以上

### 1. 准备站点内容

在 `webs/` 目录下按需添加：

- **本地站点**：创建子目录（如 `my-blog/`），并在其中放置 `index.html` 及其他静态资源。
- **代理站点**：编辑 `webs/index.json` 添加代理规则（见下方配置说明）。

### 2. 启动服务

#### 2.1 Windows
直接运行 `run.bat`，会自动安装依赖并启动服务。

#### 2.2 Linux/MacOS
直接运行 `run.sh`，会自动安装依赖并启动服务。

默认运行在 `http://localhost` 或 `http://localhost:80`，打开浏览器即可访问树形导航页。

## ⚙️ 配置说明

代理站点配置统一存放在 `webs/index.json` 中，支持两种格式：

```json
{
    "webs": [
        {
            "name": "反代站点1",
            "path": "site1",
            "url": "https://www.example.com"
        },
        {
            "name": "内部API",
            "path": "api",
            "url": "http://127.0.0.1:5001/api",
            "hide": true
        }
    ]
}
```

| 字段     | 说明 |
|--------|--|
| `name` | 在导航页面上显示的名称 |
| `path` | URL 子路径，如 `site1` 对应 `/site1/` |
| `url`  | 实际代理的后端地址（支持 HTTP/HTTPS） |
| `hide` | 可选，设置为 `true` 可隐藏在导航页面中，但仍可通过直接访问路径访问 |

> ⚠️ 若本地站点目录名与代理 `path` 重复，代理规则优先。

## 🔍 使用示例

### 访问本地站点
假设在 `webs/docs/` 下放置了静态文档：
- 浏览器打开 `http://localhost/docs/` 即可浏览。

### 访问代理站点
配置了 `path: "site1"` 且目标为 `http://127.0.0.1:5001` 时：
- 访问 `http://localhost/site1/` 将反向代理至 `http://127.0.0.1:5001/`。

### 绝对路径资源自动补全
若代理页面 `site1` 中包含 `<script src="/app.js"></script>`
- 会自动 307 重定向至 `http://localhost/site1/app.js` ，从而正确从后端获取资源。

## 🛠️ 自定义与扩展

### 修改监听端口

编辑 `app.py` 末尾：

```python
app.run(host='0.0.0.0', port=80)
```

### 调整代理超时时间

修改 `PROXY_TIMEOUT` 变量（单位：秒）。

### 关闭日志过滤

删除或注释 `LoggerFilter` 相关代码即可恢复全部请求日志。
